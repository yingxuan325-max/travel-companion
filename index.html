TRAVEL TOGETHER

怎样和朋友共享？ 🫶

目前这份代码开箱即用，但资料默认保存在当前浏览器。若要所有朋友真正同步，需要创建 Supabase 项目并填写配置。

  1. 先部署网站，让所有人都能打开同一个网址。
  2. 按照项目内 README 的步骤建立 Supabase 数据表。
  3. 把 Project URL 和 anon/publishable key 填入 js/config.js。
  4. 重新部署后，行程、花费和收藏就可以在已配置的设备间同步。

不要把 service_role key 放进前端。中国大陆访问海外托管及数据库的稳定性不能保证，请出发前实测。
