此版本 CSS 已配置字体加载规则并提供本地字体路径的说明。由于本次生成环境无法下载官方字体二进制文件，因此 ZIP 未内嵌 .ttf/.woff2 文件。当前 CSS 尝试通过 ZeoSeven 字体服务加载字体，并在失败时回退到设备上的楷体/系统字体。

如需完全离线使用，请从官方/可信字体发布页下载字体文件，并将其放在本文件夹，然后在 style.css 的 @font-face 中把 src 改为 url("assets/fonts/ZCOOLXiaoWei-Regular.woff2") format("woff2") 或对应的 .ttf 文件。请保留字体附带的授权/版权说明。
